1이 서비스는 무엇인가요

이 서비스는 AI 쇼핑 도우미입니다. 상품을 검색하고, 자연어로 질문하고(“레더 벨트를 찾아줘”), 장바구니에 담거나 쿠폰을 적용하는 일을 대화로 처리할 수 있습니다.

일반 챗봇과 다른 점은 보안 가드레일이 항상 켜져 있다는 것입니다. 입력(질문) → AI 처리 → 출력(답변)의 모든 단계를 검사해, 개인정보 유출이나 악용 시도를 자동으로 막습니다. 화면 상단의 🛡️ 보안 보호 활성 표시가 보호가 켜져 있다는 뜻입니다.

💡 알아두기AI 답변은 참고용이며 부정확할 수 있습니다. 실제 상품·주문·변경 내용은 화면에서 직접 확인해 주세요. 모든 화면 하단에 이 안내가 항상 표시됩니다.

핵심 특징

특징설명
대화형 쇼핑상품 검색·추천, 장바구니 담기, 쿠폰 적용을 AI와 대화로 진행
변경 전 확인장바구니·쿠폰을 바꾸기 전에 반드시 확인 화면을 거침. AI가 임의로 바꾸지 않음
보안 가드레일위험한 질문/답변을 자동 차단하거나, 개인정보를 가려서(마스킹) 표시
개인정보 보호주소·주민번호·전화번호는 화면에 노출하지 않음

2시작하기 — 회원가입·로그인

┌─────────────────────────────────────────────┐ │ AI 쇼핑 도우미 🛡️ 보안 보호 활성 │ │ [로그인] [회원가입] │ │ 이메일 [ ] │ │ 비밀번호 [ 숨김] │ │ [로그인 / 계정 만들기] │ └─────────────────────────────────────────────┘

회원가입

  1. 상단의 [회원가입] 탭을 누릅니다.
  2. 이메일과 비밀번호(12~128자)를 입력합니다. 비밀번호는 길고 추측하기 어렵게 만드세요.
  3. [계정 만들기]를 누르면 가입이 완료되고 로그인 탭으로 넘어갑니다.
⚠️ 참고이 화면에서는 고객 계정만 만들 수 있습니다. 관리자(관제) 계정은 별도 내부 절차로 발급되며 회원가입으로 만들 수 없습니다.

로그인·로그아웃

  • 로그인: 이메일·비밀번호 입력 후 [로그인]. 처리 중에는 버튼이 잠깁니다.
  • 로그인 정보가 틀리면 어느 항목이 틀렸는지 알려주지 않고 공통 안내만 표시합니다(보안상 의도된 동작).
  • 로그아웃은 “모든 기기에서 로그아웃”으로 동작해, 다른 기기의 로그인도 함께 해제됩니다.
💡 자동 로그인 유지페이지를 새로고침해도 로그인이 유지됩니다. 단, 브라우저 쿠키를 지우면 다시 로그인해야 합니다.

3상품 검색과 AI 도우미

로그인하면 왼쪽은 상품 영역, 오른쪽은 AI 도우미(채팅)로 나뉩니다. (모바일에서는 탭으로 전환)

┌────────────────────────────┬───────────────────────────────┐ │ 상품 검색 [ ] [검색] │ AI 도우미 │ │ [상품명 / 가격 / 재고] │ 나: 레더 벨트를 찾아줘 │ │ [상세] [장바구니 제안] │ AI: 검사 완료된 답변 │ │ … [더 보기] │ [변경 내용 확인] 만료 시각 │ │ │ [질문 입력 ][전송] │ └────────────────────────────┴───────────────────────────────┘

상품 검색

  • 검색창에 키워드(최대 100자)를 넣고 [검색]. 결과에는 상품명·가격·재고가 표시됩니다.
  • [더 보기]로 다음 목록을 이어서 봅니다.
  • [상세]를 누르면 상품 설명을 볼 수 있습니다.

AI 도우미와 대화하기

  1. 오른쪽 입력창에 질문을 자연어로 적습니다. 예: 레더 벨트를 찾아줘, 이거 재고 있어? (최대 8000자)
  2. [전송]을 누르면 “답변 생성·안전성 확인 중” 표시가 뜹니다.
  3. 검사를 통과한 정제된 답변만 화면에 나타납니다.
⏱️ 응답 시간AI 모델이 로컬 CPU에서 동작하므로 답변까지 20~50초 걸릴 수 있습니다. 한 번에 한 질문만 처리되며, 답변이 끝나기 전에는 추가 전송이 잠깁니다.

답변 상태 이해하기

표시의미
정상검사를 통과한 일반 답변
개인정보 보호민감정보가 가려진(마스킹된) 답변. 가림 표시는 서버가 넣은 것
🛡️ 차단보안 정책에 걸려 처리할 수 없는 요청. 상세 사유는 표시되지 않음
변경 확인 카드장바구니·쿠폰을 바꾸는 제안. 아직 변경된 것이 아님 → 5장 참고

4장바구니와 쿠폰

┌─────────────────────────────────────────────────┐ │ 장바구니 │ │ 상품명 단가 수량[2] [변경] [삭제] │ │ 보유 쿠폰 [선택] 조건·유효기간 [적용 제안]│ │ 적용 쿠폰: … [해제 제안] │ │ 상품 합계 / 할인 / 예상 합계 │ │ 변경은 확인 후 적용됩니다. │ └─────────────────────────────────────────────────┘

장바구니에서 할 수 있는 동작과, 각 동작이 어떻게 처리되는지입니다. 모든 변경은 “제안 → 확인” 2단계로 이뤄집니다.

하고 싶은 것방법처리
수량 변경[변경] 후 목표 수량(1~99) 입력확인 화면으로 이동
상품 삭제[삭제]확인 전에는 목록에서 사라지지 않음
쿠폰 적용보유 쿠폰 선택 → [적용 제안]본인의 사용 가능 쿠폰만 선택됨
쿠폰 해제[해제 제안]확인 후 다시 조회
💡 금액은 항상 서버 기준표시되는 모든 금액(합계·할인)은 서버가 계산한 값입니다. 재고 부족·쿠폰 만료·최소 금액 미달 등은 고정된 안내 문구로 알려줍니다. 장바구니에 담아도 재고가 예약되는 것은 아닙니다.

결제·주문 생성 버튼은 이 화면에 없습니다. 이 서비스는 장바구니·쿠폰 관리와 조회까지를 다룹니다.

5변경 내용 확인하기 (중요)

장바구니·쿠폰을 바꾸면 바로 적용되지 않고 확인 카드가 나타납니다. 내용을 직접 보고 승인해야 실제로 바뀝니다.

┌─────────────────────────────────────────────────┐ │ 변경 내용 확인 만료: 12:05 │ │ 상품: 서버에서 조회한 상품명 │ │ 수량: 1 → 2 │ │ 금액·쿠폰 변경: 서버 미리보기 │ │ [취소] [이 내용으로 변경] │ └─────────────────────────────────────────────────┘
  1. 확인 카드에 표시된 상품명·변경 전후·예상 금액·만료 시각을 확인합니다.
  2. 맞으면 [이 내용으로 변경], 아니면 [취소]를 누릅니다.
  3. 완료되면 최신 장바구니가 다시 조회되어 결과가 반영됩니다.
⏱️ 만료에 주의확인 카드에는 만료 시각이 있습니다. 시간이 지나면 “만료됨”으로 표시되고, 새로 제안을 받아야 합니다. 그 사이 가격·장바구니가 바뀌면 이전 제안은 실행되지 않습니다.
✅ 안전장치[이 내용으로 변경]을 여러 번 눌러도, 새로고침하거나 통신이 끊겨도 변경은 딱 한 번만 적용됩니다(중복 실행 방지).

6내 주문 조회

상단 메뉴의 [주문]에서 본인 주문 이력만 볼 수 있습니다.

상태의미
주문 확인(confirmed)주문이 접수됨
배송 중(shipped)배송이 시작됨
배송 완료(delivered)배송이 끝남
취소(cancelled)취소된 주문 이력
  • [상세]에서 상품명·수량·주문 당시 가격·합계를 봅니다.
  • 이 화면에서 주문 취소는 할 수 없습니다(조회 전용).
  • 개인정보 보호를 위해 주소·주민번호·전화번호는 표시되지 않습니다.

7AnythingLLM 연결 (선택 기능)

AnythingLLM 같은 외부 데스크톱 앱에서 이 쇼핑 도우미를 쓰고 싶다면, [설정] → 연결 클라이언트에서 전용 토큰을 발급받습니다.

  1. 클라이언트 이름(예: “내 데스크톱”)을 입력하고 [토큰 발급]을 누릅니다.
  2. 발급 직후 한 번만 표시되는 토큰을 [복사]해 안전한 곳에 보관합니다. (창을 닫으면 다시 볼 수 없습니다. 기본 유효기간 30일)
  3. AnythingLLM에서 아래 값으로 설정합니다.
항목값
LLM ProviderGeneric OpenAI (Ollama 아님)
Base URLhttps://shop.example.internal/v1
API Key발급받은 gct_… 토큰
Modelqwen3:8b
채팅 모드워크스페이스 ⚙ → Chat Settings → Chat (Agent/Automatic 금지)
⚠️ 인증서 설치 필요연결 전에 사내 CA 인증서(ca.crt)를 신뢰 저장소에 설치하고, 환경변수 NODE_EXTRA_CA_CERTS를 지정한 뒤 AnythingLLM을 완전히 종료·재시작해야 합니다. 안 하면 Connection error가 납니다. (설치 방법은 관리자에게 문의)
  • 연결 토큰으로는 조회·질의·변경 제안까지만 가능합니다. 실제 변경 확인은 쇼핑 웹에 로그인해서 해야 합니다.
  • 더 이상 쓰지 않는 토큰은 [폐기]하세요. 폐기하면 그 토큰의 다음 요청부터 거부됩니다.

8보안 안내 — 왜 차단되나요

이 서비스는 모든 대화를 3단계(입력·실행·출력)로 검사합니다. 다음과 같은 경우 🛡️ 차단되거나 내용이 가려질 수 있습니다.

상황서비스의 처리
다른 사람의 주문·개인정보를 요구차단. 질문에 남의 ID를 넣어도 본인 정보만 조회됩니다
AI에게 규칙·제한을 무시하라고 유도차단(프롬프트 인젝션 방어)
시스템 내부 정보·비밀을 캐내려는 질문차단
답변에 민감정보가 섞일 가능성해당 부분을 가려서(마스킹) 표시
🛡️ 차단되었을 때“보안 정책으로 처리할 수 없습니다” 같은 안내가 보이면, 질문을 정상적인 쇼핑 목적으로 바꿔서 다시 시도하세요. 상세한 차단 사유나 내부 규칙은 보안을 위해 공개되지 않습니다.
  • AI가 어떤 모델을 쓰는지 등 고정 정보는 표시될 수 있지만, 보안 검사를 끄거나 우회하는 선택지는 제공되지 않습니다.
  • 입력한 내용은 분석 도구·외부 서비스로 전송되지 않습니다. 서버에 보관되는 대화는 정제된 내용입니다.

9자주 묻는 질문·문제 해결

Q. 답변이 너무 느려요.

AI 모델이 로컬 CPU에서 동작해 20~50초가 걸릴 수 있습니다. 정상입니다. 답변이 끝날 때까지 기다려 주세요.

Q. “다른 세션이 처리 중” 안내가 떠요.

한 번에 한 질문만 처리됩니다. 이전 답변이 끝난 뒤 다시 보내거나, 새 대화를 시작하세요.

Q. 장바구니를 바꿨는데 반영이 안 돼요.

변경 확인 카드에서 [이 내용으로 변경]을 눌렀는지 확인하세요. 확인 전에는 실제로 바뀌지 않습니다. 만료되었다면 새로 제안을 받으세요(5장).

Q. 로그인/화면이 자꾸 풀려요.

브라우저 쿠키가 차단·삭제되면 로그인이 유지되지 않습니다. 쿠키를 허용한 뒤 다시 로그인하세요.

Q. 자꾸 차단돼요. 정상 질문인데요?

상품·주문 조회, 장바구니·쿠폰 관련 질문으로 다시 시도해 보세요. 그래도 안 되면 화면에 표시된 문의 번호와 함께 관리자에게 문의하세요.

Q. 사이트 접속이 안 돼요(인증서 경고).

사내 CA 인증서(ca.crt) 설치와 hosts 등록이 필요합니다. 설치 방법은 관리자에게 문의하세요.
