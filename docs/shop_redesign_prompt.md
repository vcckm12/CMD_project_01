# 쇼핑몰 꾸미기 작업 지시 (다른 AI에게 그대로 전달)

아래 `---` 이후 전체를 작업을 맡길 AI에게 그대로 붙여 넣으세요. 저장소 전체를 읽고 파일을 고칠 수 있는 코딩 AI를 전제로 합니다.

---

## 역할과 목표

당신은 웹 UI 디자이너 겸 프론트엔드 개발자입니다. 이 저장소의 **고객용 쇼핑몰 웹**(`frontend/shop/`)을 **진짜 패션 쇼핑몰처럼 더 그럴싸하게** 꾸밉니다. 동작·문구·데이터 흐름은 바꾸지 않습니다.

- 서비스: "GUARDRAIL FASHION". 패션 쇼핑몰과 AI 쇼핑 도우미가 함께 있는 시연용 쇼핑몰입니다. 질문과 답변은 AI 보안 가드레일이 검사합니다.
- 이미 있는 화면은 다음과 같습니다.
  - 메인: 무료배송 띠, 카테고리 메뉴, 배너, NEW/BEST/SALE 진열대, 전체 상품(정렬·검색), 오른쪽 AI 채팅
  - 상품 상세 (`/products/<id>`)
  - 장바구니
  - 변경 확인
  - 주문 목록·상세
  - 연결(AnythingLLM 키)
  - 로그인
- **가장 큰 과제는 상품 사진입니다.** 30개 중 12개는 단순 일러스트, 18개는 기본 상자 그림입니다. 아래 '상품 사진' 규칙에 따라 실제 사진으로 바꿉니다.
- 색 기준:
  - 먹색 `#0f172a`, 샌드 `#f8f6f2`, 골드 `#c5a880`
  - 상태색: 정상 `#047857`, 차단 `#b91c1c`, 가림 `#b45309`
  - 상태색의 의미는 유지합니다.

**수정 금지:** `frontend/shop/js/api.js`, `frontend/shop/js/dom.js`, `frontend/shop/index.html`, `backend/`(상품 데이터·서버 포함), `deployment/`, `scripts/`, `docker-compose.yml`, `frontend/ops/`

상품 이름·가격·설명 같은 데이터를 바꾸고 싶으면 직접 고치지 말고, 결과물에 **제안**으로만 적습니다.

## 절대 지킬 것 (보안)

1. **외부 리소스 금지:** 쇼핑몰은 `Content-Security-Policy: default-src 'self'; img-src 'self'; style-src 'self'; script-src 'self'`로 운영됩니다. 외부 이미지 주소(핫링크), 구글 폰트, CDN을 쓰면 브라우저가 막습니다. 이미지와 폰트는 **파일로 저장소 안에 넣어서** 같은 출처로 씁니다. 글꼴은 시스템 글꼴 스택(`"Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`)을 씁니다.
2. **인라인 스타일 금지:** HTML의 `style="…"`, `<style>`, JS에서 스타일을 직접 넣는 코드를 쓰지 않습니다. 모든 스타일은 `style.css`의 클래스로 만듭니다. 예를 들어 무료배송 막대도 `.bar .w40` 같은 클래스로 폭을 정합니다.
3. **HTML 문자열 삽입 금지:** `innerHTML`, `insertAdjacentHTML`, `outerHTML`, `document.write`를 쓰지 않습니다. 요소는 기존 `h()` 함수로 만듭니다. 상품명·AI 답변은 공격자가 조작할 수 있는 텍스트이기 때문입니다.
4. **상품 카드(`article.product`) 안의 `<img>`는 상품 사진(`.thumb`) 하나뿐이어야 합니다.** 배지·별점 같은 장식은 글자나 CSS로 만들고, `<img>`를 추가하지 않습니다. 자동 점검이 이것을 검사합니다.

## 상품 사진 규칙

- **라이선스:** 상업적 사용과 수정이 허용된 무료 라이선스 사진만 씁니다. 예: Unsplash License, Pexels License. 유료·구독 전용 사진(Unsplash+ 등), 쇼핑몰·브랜드 공식 사진, 출처를 알 수 없는 사진은 **금지**입니다. 저장소가 공개 GitHub라 특히 중요합니다.
- **받는 방법:** 사이트에서 직접 내려받거나 공식 API(개발자 키)를 씁니다. 검색 페이지를 프로그램으로 긁어 오는 방식은 쓰지 않습니다.
- **내용:** 아래 표의 상품명·색상과 비슷한 단독 상품 사진을 씁니다. 사람 얼굴이 크게 나오거나 다른 브랜드 로고가 뚜렷한 사진은 피합니다.
- **파일:**
  - 파일 이름은 `frontend/shop/img/products/<SKU>.jpg`입니다. 예: `GF-OUT-003.jpg`
  - **정사각형 800×800**, JPG 품질 80 안팎, **한 장 200KB 이하**로 맞춥니다.
- **출처 기록:** `frontend/shop/img/products/CREDITS.md`에 SKU · 사진 페이지 주소 · 작가 · 라이선스를 한 줄씩 적습니다.

## 바꾸면 안 되는 것 (자동 점검이 이 이름·문구로 화면을 찾습니다)

위치·크기·색은 바꿔도 되지만, 글자와 이름은 한 글자도 바꾸지 않습니다.

| 종류 | 그대로 둘 것 |
|---|---|
| id | `#email`, `#password`, `#q`, `#prompt`, `#main`, `#coupon`, `#token-name` |
| class | `article.product`, `.thumb`, `.bubble`과 상태 class(`me`, `bot`, `pending`, `success`, `masked`, `blocked`, `error`, `confirmation_required`), `.secret`, 장바구니의 `table` |
| 상단 메뉴 링크 | 상품·AI, 장바구니, 주문, 연결 — **다른 링크 글자에 이 단어들을 넣지 않습니다.** 예를 들어 푸터에 "주문 조회" 링크를 만들면 점검이 어느 링크인지 헷갈립니다 |
| 버튼 | 로그인, 계정 만들기, 검색(이 글자를 가진 버튼은 하나만), 장바구니 담기 제안, 전송, 이 내용으로 변경, 연결 키 발급, 확인·닫기, 모든 기기 로그아웃 |
| 링크 | 장바구니로 이동 |
| 탭 | 로그인 / 회원가입 (`role="tab"`) |
| 제목 | 변경 내용 확인, 내 주문 |
| 문구 | "계정을 만들었습니다", "장바구니가 비어 있습니다.", "변경이 적용되었습니다.", "N개 → M개" 형식, 처리 단계의 "검사 중", "🛡️ 요청을 보안 정책에 따라 처리할 수 없습니다." |
| 상품 카드 | 카드마다 수량 입력칸 하나와 "장바구니 담기 제안" 버튼 하나 |

## 디자인 요구

- **반응형:** 900px 미만에서 한 열로 쌓이게 합니다(`@media (max-width: 899px)` 유지). 휴대폰 폭에서도 카드 버튼이 카드 밖으로 넘치지 않아야 합니다.
- **접근성:**
  - 글자 대비는 WCAG AA 이상이어야 합니다.
  - 키보드 포커스가 보여야 합니다(`:focus-visible`).
  - 상품 사진의 `alt`는 상품명입니다(이미 그렇게 되어 있음).
- **애니메이션:** 쓰더라도 짧게 하고, `prefers-reduced-motion`이면 끕니다.
- **채팅 처리 단계 칩**(`.steps span.done / .now`)과 차단 답변(`.bubble.blocked`)은 시연의 핵심 장면이니 눈에 잘 띄게 유지합니다.

## 확인 방법 (작업 후 반드시)

1. **화면:** `https://shop.example.internal:8443`에서 Ctrl+F5로 새로고침합니다. 파일을 저장하면 바로 반영됩니다(빌드 불필요). 메인, 상품 상세, 장바구니, 주문 상세, 로그인 화면을 모두 봅니다.
2. **브라우저 콘솔:** 오류와 CSP 위반이 없어야 합니다.
3. **자동 점검:** 저장소 README의 "브라우저 E2E (LAB 8443 기준)" 절의 `e2e_web.py` 명령을 실행해 `console/page errors=0 csp_violations=0`이 나와야 합니다.
4. **사진:**
   - `CREDITS.md`의 줄 수와 실제로 넣은 사진 수가 같아야 합니다.
   - 파일이 한 장 200KB 이하인지 확인합니다.
