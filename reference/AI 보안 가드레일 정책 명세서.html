OWASP Top 10 기반 AI 보안 가드레일 정책 명세서 (PLN-003)

실시간 가드레일 개발 영역 4개(LLM01, 02, 06, 07) 및 시스템 아키텍처 정책 6개
1. 실시간 가드레일 엔진 개발 대상 (핵심 4대 위협)
Input Guardrail (SEC-001/002)

[LLM01] 프롬프트 인젝션 (Prompt Injection)

탈옥(Jailbreak) 키워드 및 시스템 명령 무력화 시도 실시간 차단

  • Base64 디코딩 및 유니코드 정규화를 통한 난독화 해제 후 검사
  • 정규식 기반 인젝션 패턴 탐지 시 즉시 HTTP 403 Forbidden 반환
Output Guardrail (SEC-004)

[LLM02] 불안전한 출력 처리 (Insecure Output Handling)

응답 내 악성 스크립트 실행 공격 원천 방어

  • 출력 텍스트 내 HTML/JS 태그(<script>) 무효화
  • 악성 셸 커맨드(rm -rf 등) 감지 시 스트리밍 즉시 강제 종료
Output Guardrail (SEC-003)

[LLM06] 민감 정보 노출 (Sensitive Info Disclosure)

PII(개인식별정보) 및 사내 기밀 실시간 치환

  • 주민번호, 전화번호, 이메일, API Key 감지 시 [REDACTED] 마스킹
Dual Guardrail (SEC-001 & SEC-003)

[LLM07] 시스템 지침 노출 (System Prompt Leakage)

미끼 비밀번호 및 System Prompt 유출 차단

  • 기밀 탈취 목적 질의 사전 필터링 및 역할(Role) 구조적 분리
2. 시스템 아키텍처 및 인프라 정책 (6대 환경/운영 방어)
인프라 / API 설정

[LLM04] 모델 서비스 거부 (Model DoS)

FastAPI Rate Limit 및 프롬프트 길이 제한(최대 1,000자) 적용

시스템 권한 구조

[LLM08] 과도한 권한 위임 (Excessive Agency)

SLM 모델의 외부 DB/API 쓰기 권한을 원천 차단하고 Read-Only로 제한

배포 환경 (Air-Gapped)

[LLM10] 모델 도난 (Model Theft)

기업 내부 로컬 환경에 모델 탑재 및 완전 격리 구동

데이터 파이프라인

[LLM03] 학습 데이터 오염 (Data Poisoning)

런타임 사용자 입력을 모델 재학습 데이터로 사용하지 않음

공급망 검증

[LLM05] 공급망 취약점 (Supply Chain)

공식 검증 레포지토리(Ollama) 모델만 사용하며 Checksum 무결성 검증

UI / 프론트엔드

[LLM09] 모델 과의존 (Overreliance)

Streamlit UI 하단에 환각 가능성 알림 경고 문구 상시 표시
