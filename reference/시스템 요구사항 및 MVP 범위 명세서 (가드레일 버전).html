시스템 요구사항 및 최소 구현 범위(MVP) 명세서 (PLN-002)

OWASP Top 10 for LLM 방어 4대 기능 요구사항 및 3대 비기능 품질 목표 명세서
1. 기능적 요구사항 (Functional Requirements)

[REQ-F01] 실시간 입력 필터링 (Input Guardrail)

  • 프롬프트 인젝션(OWASP LLM01) 및 탈옥(Jailbreak) 명령을 0.01초 내 감지하여 차단
  • Base64 인코딩, 유니코드 변형 등 난독화된 우회 인젝션 디코딩 후 차단

[REQ-F02] 실시간 출력 마스킹 및 XSS 방어 (Output Guardrail)

  • SLM 응답 내 개인정보(주민번호, 비밀번호, API Key) [REDACTED] 실시간 마스킹
  • HTML/JS 악성 스크립트 태그 무효화 및 악성 셸 커맨드 출력 시 스트림 강제 중단

[REQ-F03] 가드레일 토글 스위치 (Before/After 시연 컨트롤러)

  • Streamlit 상단에 [🛡️ 가드레일 ON/OFF] 토글 스위치 배치
  • 가드레일 OFF 시 취약점 유출 시연 ➔ ON 시 동일 프롬프트 실시간 방어 시연

[REQ-F04] 차단 사유 시각화 및 리포팅

  • 보안 차단 발생 시 사이드바 패널에 매칭 규칙, OWASP 위반 유형 실시간 표시
  • 대화 세션별 보안 감사 이력 및 통계 요약 리포트 PDF 출력
2. 비기능적 요구사항 (Non-Functional Requirements)

[REQ-N01] 저사양 CPU 환경 속도 보장 (Performance)

  • Intel Xeon CPU 환경에서도 초당 4~8 토큰 이상의 대화 스트리밍 응답 속도 확보
  • 가드레일 검사로 인한 추가 오버헤드 지연시간 0.03초 이내 유지

[REQ-N02] 과잉 차단 최소화 (Accuracy & FPR)

  • 공격 페이로드 방어율 95% 이상 달성 및 정상 질의 과잉 차단율(FPR) 5% 이하 유지

[REQ-N03] 경량화 및 완전 로컬 구동 (Privacy)

  • 외부 클라우드 API 없이 로컬 Qwen2.5-7B 탑재로 비용 0원 및 완전 로컬 구동 보장
